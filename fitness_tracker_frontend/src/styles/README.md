# Styles

- common.css: design tokens and global utilities adapted from `assets/common.css` and extended with the Ocean Professional theme.
- first-screen-50-41.css: exact positioning and visual styles extracted from Figma for the "Первый экран — 50:41" layout.

Usage:
- Pages import `../styles/common.css` for tokens and base, plus the screen-specific file for precision.
- Prefer keeping tokens and semantic colors in `common.css` and measurements in screen-specific files.
